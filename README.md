# termagentLang

termagentLang is a procedural language generator.

From first randomly defining an embryonic state of a language, comprising of 50 1:1
concept-to-word relations, a phonological inventory, and a pre-defined schema of a
grammar, it utilises higher-dimensional semantic vectors with algorithmic operations
(for the vocabulary) and a stochastic parallel natural-selection procedure (for the grammar) 
to simulate the evolution of a language from outside forces in a dynamic and emergent manner.

A key consideration in its design is to eliminate as many hard-coded cases as possible,
removing tendencies to make generated languages align their semantic spaces to a 
real-world counterpart.

The resultant language can be back-translated at any time by utilising the directed
acyclic graphs generated for the history of each word, and then approximating the sum
of its meaning with a dataset of English words that have also been transformed into vectors.
